Web приложение "Coin"<br>
Автор: Щербаков Игорь (is-inbox@yandex.ru)<br>

Программа сделана на компонентой основе. Вдохновлялся Vue.js (props, emits)<br>
Использовал jsx + redom для рендер функций<br>

Основные функции:<br>

Кастомный select<br>
Кастомный пагинатор<br>
Проверка карт при переводах. При вводе проверяет тип платежной системы и показывает иконку (только в форме). Посмотреть начальные номера карт можно в /src/js/cards.js<br>
Адаптив до 320px<br>
Контроль web socket соединения. Восстанавливает при разрыве.<br>
Проверка загрузки yandex maps api<br>
Центр сообщений для показа уведомлений<br>
Маски в полях ввода<br>
Индикатор загрузки приложения при входе<br>
Индикатор загрузки (в шапке) при операциях более 200ms. Проверить можно в Chrome со включенным замедлением сети "slow 3G"<br>
Мокинг транзакций. Т.к. сервер отдает данные только за текущий день + за предыдущие годы, трудно проверить графики.<br>
Для этого была сделана функция создания случайных транзакций. По умолчанию она выключена для основного счета и включена для всех новых.<br>
Как проверить: Создать новый счет и перевести на него и с него суммы (желательно крупные 500-1000 руб). Таких транзакций сделать хотя бы 3-5.<br>
Тогда будут нормальные данные для графика. Константа - useMockChartData<br>
Насчет графика за 12 мес. В ТЗ явно не указано 12 мес в течении текущего года или любые 12 мес. Я сделал оба варианта. Константа - useThisYearData<br>
Насчет формата чисел. На макете не ясно какая это локализация. Я использую русскую.<br>

Все константы для настройки в файле /src/js/init.js<br>

установка:<br>

## ssh ##

git clone git@github.com:igsproj/coin.git<br>

## https ##

git clone https://github.com/igsproj/coin.git<br>

cd coin<br>

cd server<br>

установка модулей:<br>

npm i<br>
npm upgrade<br> 

запуск dev сервера : npm start<br>

cd ..<br>
cd frontend<br>

установка модулей:<br>

npm i<br>
npm upgrade<br> 

запуск dev сервера: npm run dev<br>  
запуск сборки проекта: npm run build<br>

Для тестов нужно установить Cypress<br>
npm i -D cypress<br>
запуск тестов : npm run test<br>
