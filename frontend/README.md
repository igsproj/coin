Индикатор загрузки (в шапке) при операциях более 200ms. Проверить можно в Chrome со включенным замедлением сети "slow 3G"
Мокинг транзакций. Т.к. сервер отдает данные только за текущий день + за предыдущие годы, трудно проверить графики.
Для этого была сделана функция создания случайных транзакций. По умолчанию она выключена для основного счета и включена для всех новых.
Как проверить: Создать новый счет и перевести на него и с него суммы (желательно крупные 500-1000 руб). Таких транзакций сделать хотя бы 3-5.
Тогда будут нормальные данные для графика. Константа - useMockChartData
Насчет графика за 12 мес. В ТЗ явно не указано 12 мес в течении текущего года или любые 12 мес. Я сделал оба варианта. Константа - useThisYearData
Насчет формата чисел. На макете не ясно какая это локализация. Я использую русскую.

Все константы для настройки в файле /src/js/init.js

Тесты : Для тестов лучше установить на сервер чистый начальный конфиг, чтобы был один исходный счет. Тогда все будет четко видно.
Конфиг прикладываю - data.json
